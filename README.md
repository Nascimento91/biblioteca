# BIBLIOTECA

Sistema de gernciamento de uma biblioteca desenvovido usando PHP puro, MySQL,HTML, CSS e JavaScript.

O projeto permite cadastrar e gerenciar categorias ,livro,consultar detalhes.alem de cadastro, login e gerenciamento do perfil de usuario.

## Requisito

para executar o projeto localmente, é nescessario ter:

* **XAMPP**;
* **PHP 8 OU superior**;
* **MySQL 5.7 ou superior**;
* **Apache**;
* **Navegador Web Atualizado**;
